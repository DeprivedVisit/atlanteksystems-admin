### 5. Auth JWT + HttpOnly + Roles

**Worker (`02-Privado/panel-admin/worker/`):**
- `wrangler.toml`: name `atlantek-auth`, KV binding `AUTH_KV`, cron hourly cleanup
- `src/index.js` (ES modules, jose v5):
  - `POST /api/auth/login` — verifica password (SHA-256 vs hash), crea JWT HS256 8h, setea cookie HttpOnly Secure SameSite=Lax, guarda en KV `session:{userId}`
  - `GET /api/auth/me` — verifica JWT, chequea KV para revocación, retorna user
  - `POST /api/auth/logout` — borra KV, limpia cookie
  - `POST /api/auth/refresh` — nuevo JWT con expiry fresco, actualiza KV
  - CORS headers, OPTIONS handler
  - Roles: `admin` (*), `vendedor` (leads:r/w, clientes:r/w, docs:r, catálogo:r), `cliente` (docs:r_own, catálogo:r)

**Frontend (`assets/js/auth.js`):**
- `Auth.login(password)` → intenta Worker, fallback local (`btoa(password) === 'YXRsYW50ZWsyMDI2'`)
- `Auth.checkAuth()` → `/me` o localStorage `atlantek-auth-jwt`
- `Auth.refresh()` — auto-refresh 5 min antes de expiración (7h55m)
- `Auth.getUser()`, `hasRole()`, `hasPermission()`, `requireAuth()`
- `initPromise` evita race conditions

**Integración:**
- `admin.html`: login gate usa `Auth.login()`, muestra `user-info` en sidebar
- `app.js`: `route()` protege vistas con `Auth.getUser()`, redirige a login si no autenticado
- CSS fix: `.auth-gate.hidden { pointer-events: none }` (evita interceptar clicks)
