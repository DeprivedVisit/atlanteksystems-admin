01 · Resumen
De qué se trata este proyecto

Se desarrolló una plataforma web completa para VisionaryFilm CR — estudio de producción audiovisual en Costa Rica. El sistema incluye una landing pública para atraer clientes y un panel privado de gestión interna para administrar clientes, proyectos, pagos en USD, gastos, fondo de equipo y marketing.
