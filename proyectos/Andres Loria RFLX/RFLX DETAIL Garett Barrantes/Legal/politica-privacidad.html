Esta política aplica a los datos recopilados al agendar una cita a través del calendario del sitio web, WhatsApp o Instagram.

2. Datos que recopilamos

  • Nombre: para identificar la reserva.
  • Teléfono / WhatsApp: para confirmar horario y coordinar el servicio.
  • Dirección del servicio: para que el técnico llegue al lugar correcto.
  • Tipo y datos del vehículo: para calcular el precio del servicio.
  • Fecha y hora seleccionada: almacenada en el sistema de calendario (Google Sheets "Citas"/"Bloqueos") para evitar dobles reservas.

No recopilamos datos financieros — el pago se coordina en efectivo o SINPE directamente con el técnico.

3. Finalidad del tratamiento

  • Confirmar y coordinar la cita agendada.
  • Contactar al cliente ante cambios de horario o técnico asignado.
  • Calcular el precio según tipo de vehículo y servicio elegido.
  • Llevar control interno de agenda y bloqueos de horario.
No vendemos ni compartimos sus datos con terceros. La información de contacto y del vehículo se usa únicamente para prestar el servicio agendado.

4. Herramientas utilizadas

Google Sheets / Google Apps Script

El sistema de calendario de citas usa Google Sheets como base de datos y Google Apps Script como intermediario entre el formulario del sitio y la hoja de cálculo. Acceso restringido a Andrés Loría y a Apex Cloud Work (desarrollador del sistema).

WhatsApp / Instagram

Canales de contacto y confirmación. Al escribir por esos medios usted acepta los términos propios de cada plataforma (WhatsApp, Meta/Instagram).

5. Conservación de datos

Los datos de una cita se conservan mientras exista una relación de servicio activa o reciente con el cliente. Datos de citas antiguas sin actividad se pueden depurar periódicamente del Sheet de control.

6. Sus derechos

Conforme a la Ley N.° 8968 de Costa Rica, usted tiene derecho de acceso, rectificación, cancelación y oposición sobre sus datos. Escríbanos a reflexdetail323@gmail.com o WhatsApp +506 7035-2618.

7. Modificaciones

Esta política puede actualizarse en cualquier momento. Versión vigente disponible en esta misma página.
