03 // SEGURIDAD

Vulnerabilidades de Seguridad

Vulnerabilidades identificadas ordenadas por nivel de riesgo.

VulnerabilidadRiesgoDetalle y solución
Sin Content Security Policy (CSP) 🔴 Alto No hay header CSP. XSS puede exfiltrar datos. Configurar en CloudFront Response Headers Policy.
innerHTML en animación Claude 🔴 Alto el.innerHTML = '' en script.js línea 81. Hardcoded ahora, XSS si viene de API. Usar createElement + textContent.
admin.html sin autenticación 🟡 Medio Accesible públicamente. Si se conecta a Sheets reales → exposición de datos. Proteger con Cognito o password gate.
onclick inline en HTML 🟡 Medio Impide CSP strict-dynamic. Migrar todos los onclick a addEventListener en script.js.
Sin X-Frame-Options 🟡 Medio Expuesto a clickjacking. Añadir X-Frame-Options: SAMEORIGIN en CloudFront.
Sin X-Content-Type-Options 🟡 Medio Añadir X-Content-Type-Options: nosniff en CloudFront headers.
Portal sin autenticación real 🟡 Medio portal/index.html carece de auth real. Implementar Cognito User Pool antes de conectar datos reales.
Sin Referrer-Policy 🟢 Bajo Referrer-Policy: strict-origin-when-cross-origin
Sin Permissions-Policy 🟢 Bajo camera=(), microphone=(), geolocation=()
Sin SRI en Tailwind CDN 🟢 Bajo Si se usa Tailwind CDN → añadir integrity="sha384-...".

05 // CSS / JS

Calidad de Código

Ejemplos concretos antes/después de los problemas más importantes.

ANTES — Contraste insuficiente

:root {
  --text2: #7B7B96; /* ratio 3.8:1 ❌ */
  --text3: #42425A; /* ratio 2.4:1 ❌ */
}

DESPUÉS — WCAG AA compliant

:root {
  --text2: #9494B0; /* ratio 4.6:1 ✅ */
  --text3: #68688A; /* ratio 3.2:1 ✅ grandes */
}

ANTES — onclick inline (HTML)

<button
  onclick="toggleStep(this)"
  aria-expanded="true">

DESPUÉS — addEventListener (JS)

// script.js — sin onclick en HTML
document.querySelectorAll('.proc-btn')
  .forEach(btn => {
    btn.addEventListener('click',
      () => toggleStep(btn));
  });

ANTES — innerHTML XSS risk

// script.js línea 81 ⚠️
if(mIdx >= messages.length) {
  mIdx = 0;
  el.innerHTML = ''; // ← riesgo XSS
}

DESPUÉS — DOM seguro

// Limpiar sin innerHTML
while(el.firstChild) {
  el.removeChild(el.firstChild);
}
// Crear elementos seguros:
const span = document.createElement('span');
span.textContent = texto; // ✅
