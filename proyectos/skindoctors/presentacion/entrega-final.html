1Activar N8N para CBD Oil Balance

El workflow de N8N para CBD está listo para importar. Seguir estos pasos en apexcloudworkscompany.app.n8n.cloud:

Tiempo estimado: 15 minutos · Requiere acceso a la cuenta N8N de Apex Cloud Work. 
Paso 1: ir a apexcloudworkscompany.app.n8n.cloud
Paso 2: Workflows → Import from File → seleccionar n8n-workflow-melasblock.json
Paso 3: Renombrar workflow a "CBD Oil Balance — Leads"
Paso 4: En nodo "Formatear Datos":
         $json.body.tono  →  $json.body.piel
         label "Tono"         →  "Tipo de Piel"
Paso 5: En nodos de Sheets: reemplazar Sheet ID de Melasblock por ID del Sheet CBD
Paso 6: Activar workflow con el toggle → copiar URL del webhook generada
Paso 7: Pegar URL en cbd-balance/index.html → const N8N_WEBHOOK = 'URL'

2Cambiar número de WhatsApp

Actualmente las landings usan el número temporal de Apex Cloud Work (+506 6314-4171). Al firmar, reemplazar con el número oficial de Skindoctors en ambos archivos.

── melasblock/Mellas/index.html ── buscar línea ~1106:
const WA_NUMBER = '506XXXXXXXXX'; ← reemplazar con número Skindoctors (sin +)

── cbd-balance/index.html ── buscar línea ~829:
const WA_NUMBER = '506XXXXXXXXX'; ← mismo número

Después del cambio, subir al S3 con AWS CLI:
aws s3 cp melasblock/Mellas/index.html s3://skindoctors-cr-landings/melasblock/index.html
aws s3 cp cbd-balance/index.html s3://skindoctors-cr-landings/cbd-balance/index.html
aws cloudfront create-invalidation --distribution-id E31U5V9IA0JXSZ --paths "/*"
¿Por qué el número sin +? WhatsApp API usa formato internacional sin el símbolo +. Ejemplo: +506 8888-8888 → 50688888888
