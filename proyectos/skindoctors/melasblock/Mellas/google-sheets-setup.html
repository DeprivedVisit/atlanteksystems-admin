Setup Google Sheets · Leads Melasblock

Sigue estos 4 pasos para conectar el formulario de la landing con Google Sheets. Tiempo estimado: 8 minutos.

1Crear el Google Sheet

Abrí sheets.google.com y creá una hoja nueva. Llamala "Leads Melasblock". Copiá el ID de la URL (la parte larga entre /d/ y /edit).

URL ejemplo: docs.google.com/spreadsheets/d/1BxiMVs0XRA5nFMdKvBdBZjgmUUqptlbs74OgVE2upms/edit
El ID es la parte en negrita.

2Crear el Apps Script

Dentro del Sheet: Extensiones → Apps Script. Borrá el código existente y pegá este:

// ── Melasblock Lead Capture · Apex Cloud Works ──
const SHEET_ID   = 'PEGÁ_TU_SHEET_ID_AQUI';
const SHEET_NAME = 'Leads';

function doPost(e) {
  try {
    const sheet = SpreadsheetApp
      .openById(SHEET_ID)
      .getSheetByName(SHEET_NAME)
      || SpreadsheetApp.openById(SHEET_ID).getActiveSheet();

    // Encabezados en primera fila si está vacía
    if (sheet.getLastRow() === 0) {
      sheet.appendRow([
        'Fecha', 'Nombre', 'Teléfono', 'Email',
        'Tono', 'Provincia', 'Contexto', 'Fuente'
      ]);
      // Formato encabezados
      sheet.getRange(1, 1, 1, 7)
        .setBackground('#8F6149')
        .setFontColor('#FFFFFF')
        .setFontWeight('bold');
    }

    const d = JSON.parse(e.postData.contents);

    sheet.appendRow([
      new Date().toLocaleString('es-CR'),
      d.nombre    || '',
      d.telefono  || '',
      d.email     || '',
      d.tono      || 'No especificado',
      d.zona      || '',
      d.contexto  || '',
      'Melasblock Landing'
    ]);

    return ContentService
      .createTextOutput(JSON.stringify({ status: 'ok' }))
      .setMimeType(ContentService.MimeType.JSON);

  } catch (err) {
    return ContentService
      .createTextOutput(JSON.stringify({
        status: 'error',
        msg: err.toString()
      }))
      .setMimeType(ContentService.MimeType.JSON);
  }
}

// Test de conexión (GET)
function doGet() {
  return ContentService
    .createTextOutput('Melasblock Leads API · OK');
}
Importante: Reemplazá PEGÁ_TU_SHEET_ID_AQUI con el ID de tu hoja.

3Deployar como Web App

En el editor de Apps Script: Implementar → Nueva implementación

  • Tipo: Aplicación web
  • Ejecutar como: Yo (mi cuenta de Google)
  • Quién tiene acceso: Cualquier persona
  • Hacé clic en Implementar
  • Copiá la URL de la aplicación web que aparece
La URL tiene este formato:
https://script.google.com/macros/s/AKfycb.../exec

4Pegar la URL en la landing

Abrí index.html, buscá esta línea cerca del inicio del bloque <script> y reemplazá el placeholder:

// Antes:
const SHEETS_URL = 'TU_APPS_SCRIPT_URL_AQUI';

// Después (pegá tu URL real):
const SHEETS_URL = 'https://script.google.com/macros/s/TU_ID/exec';

¿Cómo funciona? Cuando un usuario llena el formulario y hace clic en "Continuar a WhatsApp", el formulario envía los datos al Apps Script en segundo plano (sin que el usuario lo note), se guardan en el Sheet, y se abre WhatsApp con el mensaje pre-llenado. Si el Script falla por alguna razón, WhatsApp se abre igual — el usuario nunca es bloqueado.
